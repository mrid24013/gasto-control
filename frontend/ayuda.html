Manual de Usuario

Sistema de Control de Gastos Personales

El presente manual tiene como objetivo guiar al usuario en el uso del sistema de Control de Gastos Personales, el cual permite registrar ingresos, egresos y visualizar reportes de manera sencilla.

Este sistema está diseñado para ser intuitivo, sin embargo, este manual facilitará el aprendizaje y resolverá dudas comunes.

Registro de Usuario

  1. Ingresar a la página.
  2. Dar clic en el botón “Registrar”.
  3. Completar los campos:
    • Usuario
    • Contraseña
    • Confirmación de la contraseña
  4. Presionar el botón “Registrar”.
Nota:
  • El usuario debe ser único.
  • La contraseña debe cumplir con los requisitos mínimos de seguridad señalados en la página.

Inicio de Sesión

  1. Ingresar a la página.
  2. Escribir:
    • Usuario
    • Contraseña
  3. Dar clic en “Ingresar”.
  4. El usuario será redirigido al panel principal (Home).

Panel Principal (Dashboard)

En esta sección el usuario puede visualizar:

  • Resumen de ingresos
  • Resumen de gastos
  • Balance total
  • Opción para exportar movimientos totales
  • Accesos rápidos a:
    • Crear Movimiento
    • Crear Categoría
    • Cerrar sesión
  • Tablas de movimientos con:
    • Organización por mes
    • Opción para Editar Movimiento.
    • Opción para Eliminar Movimiento
    • Opción para exportar movimientos de ese mes

Gestión de Categorías

  1. Si ya se tiene una categoría:
    • Dar clic en "Ver Categorias" y ver las siguientes opciones.
    • Observar las categorías existentes.
    • Editar categorías.
    • Eliminar categorías
    • Opcion de "Agregar Categoría" estara disponible con los mismos pasos de abajo
  2. Si NO se tiene una categoría:
    • Dar clic en “Agregar Categoría”.
    • Escribir el nombre de la categoría (Ej: Comida, Transporte).
    • Seleccionar si es gasto o ingreso.
    • Guardar.
    • La categoría quedará disponible para usar en movimientos.

Registrar Movimiento (Ingreso o Gasto)

  1. Dar clic en “Agregar Movimiento”.
  2. Completar los campos:
    • Monto
    • Fecha
    • Descripción
    • Categoría
  3. Presionar “Guardar”.
Nota:
  • Debe existir al menos una categoría.
  • El monto debe ser un número válido.

Editar Registros (Categorías o Movimientos)

  1. Dar clic en opción “Editar”.
  2. Editar los campos
  3. Para Movimiento:
    • Monto
    • Fecha
    • Descripción
    • Categoría
  4. Para categoría:
    • Nombre de la categoría (Ej: Comida, Transporte).
    • Gasto o Ingreso.
  5. Presionar “Guardar” o "Cancelar" en caso de querer regresar a la pantalla anterior sin alterar los registros.

Borrar Registros (Categorías o Movimientos)

  1. Dar clic en opción “Borrar”.
  2. Para Movimiento:
    • Revisar notificación emergente
    • Aceptar o Cancelar
  3. Para categoría:
    • Revisar notificación emergente
    • Aceptar o Cancelar
Nota:
  • Para poder eliminar una categoría no debe de estar ligada a ningun movimiento.

Exportación de Datos

  1. El usuario puede exportar información en formato CSV:
    • Exportación general
    • Exportación por mes
  2. Presionar “Exportar” y descargar archivos (.csv).
Nota:
  • Debe existir al menos un movimiento.

Cerrar Sesión

  1. Dar clic en el botón “Cerrar sesión” en la barra superior.
  2. El usuario será redirigido a la pantalla de login.

Problemas Comunes y Soluciones

“No puedo crear un movimiento”
Causa: No existen categorías registradas
Solución: Crear una categoría primero
“No puedo iniciar sesión”
Causa: Usuario o contraseña incorrectos
Solución: Verificar datos o registrarse nuevamente
“No se guardan los datos”
Causa: Campos incompletos
Solución: Llenar todos los campos obligatorios
“No veo cambios reflejados”
Causa: No se actualizó la página
Solución: Recargar el navegador
